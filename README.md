# ms
A stupid little minesweeper game in zig with raylib.

## Features
- Infinite board
- Both mouse and keyboard controls
- Flag only mode
- Cool cocos-like UI library I went overboard with making
- A cool little inspector for the UI library
- Quick reveal (i dont remember what its actual name is)
- A couple biomes
